# 🎯 نظام الفصل بين الاشتراكات — تصميم شامل

## 📋 المتطلبات الأساسية

### ✅ قيود إلزامية:
1. **عدم المساس ببروتوكول الحظر** — كل آليات الحظر/السماح تبقى كما هي
2. **المزامنة مع صفحة الأدمن** — تحديثات فورية (Realtime)
3. **راحة الاستخدام** — واجهة بديهية وسريعة

## 1️⃣ **التصميم المعماري**

### أ) **الفصل بالـ Tabs (الأبواب)**

```
┌─────────────────────────────────────────────────────────┐
│  الكل (15)  │  مجاني (8)  │  أساسي (4)  │  متقدم (3)  │
└─────────────────────────────────────────────────────────┘
```

**المزايا:**
- رؤية سريعة لعدد المستخدمين في كل خطة
- التنقل بنقرة واحدة
- فلترة تلقائية

### ب) **نظام البحث والفلترة**

```tsx
┌─────────────────────────────────────────────────────────┐
│  🔍 بحث (البريد، الاسم)   [نشط ▼] [الكل ▼]  [تحديث]  │
└─────────────────────────────────────────────────────────┘
```

**الفلاتر:**
- **الحالة:** الكل / نشط / موقوف / محظور / منتهٍ
- **الخطة:** الكل / مجاني / أساسي / متقدم
- **البحث:** نص حر (userId، email)

### ج) **البطاقات (Cards) بدلاً من الجدول**

```
┌────────────────────────────────────────────┐
│  👤 user@example.com                       │
│  📦 أساسي  •  ✅ نشط  •  متبقٍ 25 يوم    │
│  📊 2/5 منتجات  •  3/5 صور               │
│                                            │
│  [تعديل]  [إيقاف]  [تجديد]  [•••]        │
└────────────────────────────────────────────┘
```

**مزايا البطاقات:**
- أكثر قابلية للقراءة
- responsive أفضل للموبايل
- مساحة أكبر للمعلومات

## 9️⃣ **مزامنة Realtime**

### آلية المزامنة:

```typescript
// في AdminPanel.tsx
useEffect(() => {
  // الاشتراك في تغييرات الاشتراكات
  const channel = supabase
    .channel('subscriptions')
    .on('postgres_changes', 
      { event: '*', schema: 'public', table: 'kv', filter: 'key=like.subs/%' },
      (payload) => {
        // تحديث القائمة فوراً
        refreshSubscriptions();
      }
    )
    .subscribe();
    
  return () => { channel.unsubscribe(); };
}, []);
```

**النتيجة:**
- تغيير من أدمن آخر → تحديث فوري
- تغيير من المستخدم (upgrade) → ظهور فوري
- انتهاء صلاحية → تحديث تلقائي
