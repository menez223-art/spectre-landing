# Checkpoint فرعي — المرحلة 2: عينات الدفعة الثانية + الفهرس

التاريخ: 2026-11-20 · الحالة: ✅ **مقبولة من المالك — 9/10** («عمل ممتاز 9/10 أنا موافق عليه»)
النطاق: تصميم فقط في `design-samples/`. لا كود مشروع حقيقي مُسّ. نظام الحظر/السماح لم يُمس (العينات عرض-only بأزرار خاملة).

## الملفات (وكيلان متزامنان، qwen 4 max)
- `guest.html` (~99KB) — استوديو الزائر الكامل (نموذج GuestStudio بكل أقسام المصدر) + TrialPanel بكل حالاته (نموذج/رمز مُرسل/مؤكد/مُنشأ/منتهٍ/محوّل/معطّل/خطأ/حذف/استعادة). تفاعل تجريبي خفيف (رمز 246810 ينجح، تحقق إيميل/واتساب 213). معاينة نائبة موسومة.
- `loading.html` (~13KB) — هياكل تحميل ثابتة بالأبعاد الحرفية للمصدر (رئيسية/تسعير/استوديو) + شريط تقدم 2px بلون primary. بلا أنيميشن نابض (قاعدة الجهاز الضعيف).
- `admin-login.html` (~11KB) — بطاقة دخول المشرف بنمط studio-login + حالة Modal (غلاف AdminLoginModal).
- `admin.html` (~144KB) — لوحة الأدمن الكاملة: إحصائيات + توزيع خطط، تحذيرات ذكية، بحث/فلترة/تبويبات/ترتيب، بطاقات مشتركين (شارات/أشرطة حصص/تحكم خطة/أيام/إيقاف/حظر/حذف)، محظورون، صحة روابط، منتجات المتجر، احتياط/سعة/تخزين. نوافذ: ConfirmDialog عامة، ProductEdit، GuestTrials، SiteCopy (37 نصاً/7 مجموعات)، Credentials، Storage — تفتح من أزرارها ومن شريط المراجعة.
- `index.html` — فهرس العينات (بطاقات قابلة للنقر لكل صفحة + شارات القبول + تعليمات المراجعة + القرارات).

## تحقق الأب (لا يُوثق بتقرير الوكيل وحده)
- `check.mjs`: **ALL PASS** للملفات الخمسة (admin تحذير ∞← مقصود: قيم افتراضية حرفية لمفتاحي statPages/subsCta تظهر كـplaceholder في محرر site-copy — بيانات لا زخرفة).
- متصفح حقيقي 1366×768: صفر فيضان أفقي بالوضعين · خطوط/أيقونات محمّلة · الثيم/اللغة/RTL تعمل · أزرار الحالات الحقيقية تغيّر الحالة (مع استثناء زر التصغير المحقون).
- **النوافذ تفتح فعلياً** (تأكيد بصري): Confirm Ban في الأدمن، تأكيد الحذف في الزائر، وضع Modal لدخول الأدمن — كلها scrim + بطاقة مركزية + أزرار، بلا تشوه.
- أقسام الأدمن السفلية مؤكدة بصرياً: بطاقات المشتركين (حصص/شارات/أزرار)، صحة الروابط (Healthy)، منتجات المتجر (Listed/Hidden/Private/Banned + أزرار)، الاحتياط/التخزين.
- **بلاغ «ازدواج الحروف» في العناوين/المسارات: فُحص بتكبير بكسلي → النص سليم single-struck، لا ازدواج.** كان وهماً من تصغير الصورة + نص رمادي صغير. لا عيب.
- هيكل التحميل: مطابق للمصدر حرفياً (البطل مركزي mx-auto max-w-2xl والبطاقات max-w-xl يساراً — نفس سلوك app/loading.tsx، ليس عيباً).
- **تحسين مركزي:** شريط المراجعة المصغّر (زر +) نُقل إلى الزاوية السفلية اليمنى بدل المنتصف كي لا يغطي المحتوى (tokens.css).

## قرارات/انحرافات موثّقة (يحكم فيها المالك)
- guest/loading شاشات مستقلة بلا ترويسة/تذييل (المصدر نافذة حوار / main فقط) — أزرار ثيم/لغة عائمة.
- **افتراضي لغة الأدمن EN** في العينة (آلية shared.js الموحدة) بينما AdminLocale الحقيقي افتراضيه AR بمفتاح منفصل `admin-panel-lang` — التبديل يعمل؛ يُراجع عند التطبيق.
- window.confirm الحقيقية → ConfirmDialog بنمط neu-overlay (العنوان من تسمية الإجراء).
- بيانات تجريبية موسومة (8 مشتركين، إحصائيات محسوبة منها: 8/5/18000دج/2، خطط 4/2/2، حصص PLAN_QUOTAS الفعلية). كل الأزرار خاملة/محلية، لا API ولا منطق حظر.
- الروابط الخارجية خاملة (#) أو عينات محلية. العدّاد ثابت موسوم (بلا مؤقّت حي).
- لا ThemeSelector (قرار المرحلة 0، مقبول ضمنياً بقبول الدفعة الأولى).
