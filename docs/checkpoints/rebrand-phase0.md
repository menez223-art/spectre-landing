# Checkpoint فرعي — المرحلة 0: الأساس المشترك (إعادة الهوية البصرية)

التاريخ: 2026-11-20 · الحالة: ✅ منجزة ومُتحقَّق منها
النطاق: **تصميم فقط** — لا كود مشروع حقيقي مُسّ. كل المخرجات في `design-samples/`.
المرجع: هوية Neumorphism من كود HTML الذي زوّده المالك (ملف مرفق 2026-11-19).

## المنجز
- **أصول محلية 100%:** Cairo + Poppins (woff2 عربي/لاتيني) + Font Awesome 6.4.0 (solid/regular/brands/v4compat) — العينات تعمل دون إنترنت. لا CDN.
- **`assets/css/tokens.css`:** قيم الهوية حرفياً من كود المالك (فاتح `#e0e5ec`/ليلي `#212529`، ظلال outer/inner/active) + معمّمات (بطاقة 30px/لوحة 20px/عنصر 15px، زر/حقل/تسمية عائمة/شارة/تبويب/نافذة/تقدم/صف) + ألوان حالات مشتقة من نفس عائلة اللوحة (نجاح/تنبيه/خطأ — للنص والأيقونة فقط، لا خلفيات ملونة).
- **`assets/js/shared.js`:** ثيم (`data-theme` + قمر/شمس) + لغة (`data-en`/`data-ar` + قلب RTL) + عين كلمة المرور + حفظ localStorage (مفتاح اللغة نفسه للمشروع `landing-studio-lang`) + زر تصغير شريط المراجعة. يُحمَّل في head بلا وميض.
- **العينة المرجعية `studio-login.html`:** مُتحقَّق منها بالمتصفح — الوضعان، اللغتان، RTL (التسمية العائمة/العين تنقلبان)، الخطوط (Cairo عربي/Poppins لاتيني)، أيقونات FA، صفر فيضان، لا تداخل مع شريط المراجعة.
- **`BRIEF.md` + `check.mjs`:** موجز الوكلاء + فاحص (لا روابط خارجية، تكافؤ data-en/ar، لا إيموجي، الأصول والأزرار موجودة).

## قرارات موثّقة
- الانتقالات محصورة بالعناصر التفاعلية (لا `*`) — جهاز ضعيف (i5-5200U نواتان/12GB).
- لا blur/backdrop-filter ثقيل ولا أنيميشن مستمر.
- **ThemeSelector (منتقي الألوان السداسي) غير موجود في كود الهوية الجديدة** (لوحة ثابتة) ⇒ حُذف من العينات، واقتصر التحكم على زرّي الثيم/اللغة كما الكود. **مُعلَم للمالك — قراره عند المراجعة.**
- صفحات الهبوط (`/p/[slug]` + `app/components/landing/*`) خارج النطاق تماماً.
